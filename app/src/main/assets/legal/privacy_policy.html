YukiBoard 隱私權政策

最後更新：2026 年 4 月 11 日

1. 資料控管者

YukiBoard 由 SnowRealm 團隊開發與營運。如有隱私相關問題，請聯繫：privacy@snowrealm.pet

2. 我們收集的資料

2.1 本機處理（不上傳）

  • 打字內容：注音組字、候選字選擇僅在裝置本機處理，不會傳送至任何伺服器
  • 剪貼簿歷史：儲存於裝置本機 SharedPreferences
  • 使用者字典：自訂詞彙儲存於裝置本機
  • 打字習慣：詞頻統計僅用於本機候選字排序
  • 感測器資料：加速度計、陀螺儀資料僅用於搖晃復原和游標控制，不儲存不上傳

2.2 可能上傳的資料（需使用者主動啟用）

  • 語音輸入：使用 Android SpeechRecognizer 或 Whisper API 時，語音資料依各服務隱私政策處理
  • AI 功能：使用 AI 候選字建議時，輸入內容可能傳送至 OpenAI / Anthropic API
  • 翻譯功能：使用翻譯面板時，文字可能傳送至翻譯服務 API
  • GIF 搜尋：搜尋關鍵字可能傳送至 Giphy / Tenor API
  • 帳號登入：使用 SnowRealm 帳號時，基本資料（電子郵件、顯示名稱）儲存於 Supabase

3. 資料使用目的

  • 提供輸入法核心功能（候選字、自動更正、詞頻學習）
  • 改善使用者體驗（主題設定、鍵盤偏好同步）
  • 提供 AI 輔助功能（需使用者主動啟用並提供 API Key）

4. 資料儲存與安全

  • 本機資料使用 Android SharedPreferences 儲存，敏感資料使用 EncryptedSharedPreferences
  • 網路通訊強制使用 HTTPS（TLS 1.2+）
  • API Key 由使用者自行管理，不儲存於我們的伺服器
  • 藍牙 HID 鍵盤通訊使用標準 BLE 加密

5. 第三方服務

YukiBoard 可能整合以下第三方服務，各服務有獨立的隱私政策：

  • Firebase（崩潰報告、應用分發）— Firebase Privacy
  • Supabase（帳號系統）— Supabase Privacy
  • OpenAI / Anthropic（AI 功能）— 依各服務條款

6. 使用者權利

依據台灣《個人資料保護法》(PDPA)、歐盟 GDPR、美國 CCPA，您享有以下權利：

  • 存取權：查閱我們持有的您的個人資料
  • 更正權：要求更正不正確的資料
  • 刪除權：要求刪除您的資料（設定 → 清除所有資料）
  • 可攜權：以通用格式匯出您的資料
  • 反對權：拒絕特定資料處理
  • 撤回同意權：隨時撤回先前給予的同意

7. 兒童隱私

YukiBoard 不會故意收集 13 歲以下兒童的個人資料。若發現誤收集，我們將立即刪除。

8. Cookie 與追蹤

YukiBoard 為本機應用程式，不使用 Cookie。Firebase Analytics 可在設定中停用。

9. 國際資料傳輸

使用 AI 或翻譯功能時，資料可能傳輸至美國或其他國家的伺服器。我們確保所有傳輸符合適用的資料保護法規。

10. 政策變更

本政策變更時，我們會透過應用程式更新通知您。重大變更需要您重新同意。
